# @rollout/demo

Minimal demo app for showcasing components from `@rollout/ui-kit` and `@rollout/ui-features`.

> This demo uses **React 19**.

## Commands

```bash
pnpm --filter @rollout/demo dev
pnpm --filter @rollout/demo build
pnpm --filter @rollout/demo lint
pnpm --filter @rollout/demo test
```
