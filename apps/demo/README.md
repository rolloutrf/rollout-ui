# @rollout/demo

Демо-приложение для демонстрации использования компонентов из `@rollout/ui-kit` и `@rollout/ui-features`.

> Для демо используется **React 19**.

## Команды

```bash
# Из корня монорепозитория
pnpm demo

# Или напрямую
pnpm --filter @rollout/demo dev
pnpm --filter @rollout/demo build
pnpm --filter @rollout/demo lint
pnpm --filter @rollout/demo test
```
